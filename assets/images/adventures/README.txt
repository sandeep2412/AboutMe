.jpg, either rename it to match or update the src in adventures.html.

Until a file exists, that card falls back to a dark placeholder with an
icon, so the page still looks intentional either way.

Recommended: roughly 4:3 landscape photos, compressed to a reasonable size
(a few hundred KB) so the page stays fast to load. Portrait photos are fine
too — they get cropped to fit the 4:3 frame via object-fit: cover, centered
by default.
