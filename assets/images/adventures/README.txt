Drop your photos into this folder using these exact filenames — adventures.html
already references them, so each one will appear automatically once added.
No file extension changes needed elsewhere; if your photo is a .png instead of
.jpg, either rename it to match or update the src in adventures.html.

  panch-kedar.jpg   -> Panch Kedar Circuit card
  summit.jpg        -> Summit Expeditions card
  solo-trek.jpg     -> Solo Treks card
  delhi-trails.jpg  -> Delhi Trails card
  run-5k.jpg        -> 5K Run card
  run-10k.jpg       -> 10K Run card

Until a file exists, that card falls back to a dark placeholder with a
mountain icon, so the page still looks intentional either way.

Recommended: roughly 4:3 landscape photos, compressed to a reasonable size
(a few hundred KB) so the page stays fast to load.
